Blue Mission — Ocean-Safety Learning Game

Educational product on marine safety and ocean care: a 2D mini-game mobile app for students, a web portal for teachers and admins, and a single REST API that owns every rule.

The goal

Teach marine safety through play while giving teachers reports, materials and a question bank.

Solution

I built an educational product about marine safety and ocean care as three clients around one API.

  • Student app (Expo / React Native): three levels (clean the beach, clean the sea, save marine life), each running the same loop: collect trash → sort trash → mandatory quiz. I embedded the Phaser gameplay inside the app.
  • Teacher & admin portal (React + Vite): class reports, learning materials and a question bank, with the same role permissions as the mobile app.
  • API (Bun + Elysia + Prisma + MySQL): the only place business rules live. I designed the clients to send activity counts, never scores, so results can’t be tampered with on the device.

Architecture

I chose server-authoritative scoring to keep the rules in one place, so all three clients stay consistent. The API is specified in OpenAPI and covered by bun:test, and it runs in Docker.

Highlights

  • One API owns every rule: points, pass/fail, unlocking and ranking are computed server-side
  • 54 documented endpoints with OpenAPI and 246 automated tests
  • Phaser mini-game embedded in a React Native (Expo) app
  • Separate web portal for teachers and admins: reports, learning materials and a question bank

Outcome

  • MVP API feature-complete: 54 documented endpoints backed by 246 automated tests
