Skorindigital — Real-time Sports Scoreboard SaaS

Real-time scoreboard for live matches, viewable on venue TVs and phones, with an API for integrating scores into other systems.

The goal

Let any event organiser run a professional live scoreboard from a phone, without scoreboard hardware.

Solution

Skorindigital is a SaaS scoreboard for live matches that I designed and built end to end. An event organiser signs up, creates an event and its matches, and keeps the score from a phone. The score updates instantly on a TV display at the venue and on any spectator’s phone.

I set the product up on paid plans (free, monthly and per-event) whose limits are enforced in the app. Organisers can also expose scores to their own systems through API keys.

Architecture

Next.js with NextAuth v5, Prisma on PostgreSQL, Socket.IO with a Redis adapter for real-time fan-out, S3 for assets, and Docker with Nginx.

Highlights

  • Live scores pushed to venue TVs and phones in real time (Socket.IO + Redis)
  • Self-service sign-up with Google SSO, events and matches
  • Membership plans (free, monthly, per-event) with limits enforced by plan
  • Public, private and display URLs per match
  • API keys for pushing scores into other systems

Outcome

  • Shipped v2 with self-service sign-up, paid plans and a public score API
